# EGFR data processing scripts and files

- `comet parameters.txt`: Comet MS/MS search engine parameters file
- `data_processing.pdf`: R markdown output from normalization and statistical tests of the three mass spectrometry replicates
- `EGFRUtil.py`: utility functions used by multiple Jupyter notebooks
- `heatmap*.m`: MATLAB scripts for making heatmaps of the phosphorylation data
- `notebooks`: a subdirectory of Jupyter notebooks for data exploration and visualization
- `pcsf`: a subdirectory of scripts and files for running the prize-collecting Steiner forest algorithm on a Sun Grid Engine cluster for multiple datasets

The prize-collecting Steiner forest code was similar to the derived [`PCSF.py`](https://github.com/agitter/MultiPCSF/blob/ecfcf1b5a01c9e739890f63d4bcba1e909fad363/PCSF.py) from Multi-PCSF.
